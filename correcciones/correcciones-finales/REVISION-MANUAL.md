# Revisión manual · VIE Publicación

**Responsable:** ____________________ · **Fecha:** ____________________

Realizar con el perfil VIE Publicación y datos de prueba. Las comprobaciones automáticas se documentan aparte; no completan estas casillas.

- [X] **Acceso:** dejar correo o contraseña vacíos. Comprobar mensajes en español, foco y campo marcado. Repetir con navegador configurado en inglés.
- [X] **Inicio:** comprobar que los cierres próximos corresponden a publicadas sin vencer, ordenadas por fecha; abrir un elemento y verificar que lleva a su propia convocatoria.
- [X] **Listado:** buscar por nombre y filtrar estado. Plegar y limpiar cada criterio por separado; comprobar que el otro permanece aplicado.
- [X] **Crear:** comprobar pantalla propia sin listado ni IDs. Intentar guardar vacío, con fecha inexistente, cierre anterior o responsable vacío; revisar el mensaje exacto y la señalización.
- [X] **Crear:** introducir presupuesto con decimales y actividad posterior al cierre de recepción. Guardar y comprobar confirmación y relectura.
- [X] **Editar:** abrir un borrador, cambiar actividad/responsable y guardar. Recargar y comprobar que se conserva lo guardado y no se duplican actividades.
- [X] **Revisar:** comprobar claridad del nombre, estado, descripción, fechas `DD-MM-AAAA`, presupuesto, actividades y responsables.
- [X] **Publicar/cerrar/reactivar:** revisar confirmación, cancelar y comprobar que no cambió el estado. Confirmar después y verificar el resultado.
- [X] **Eliminar:** comprobar advertencia y cancelación. Utilizar únicamente un borrador de prueba sin propuestas; verificar el mensaje posterior.
- [X] **Histórico:** probar filtros independientes, limpieza global y lectura de fechas del expediente.
- [X] **Notificaciones:** comprobar lectura, fechas y ausencia de mensajes técnicos o de servicio en inglés.
- [X] **Móvil y teclado:** revisar a 390 px, navegar con Tab, comprobar foco y legibilidad del cronograma. Repetir con alto contraste.
