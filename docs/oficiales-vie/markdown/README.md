# Oficiales VIE — Markdown (markitdown)

Convertidos con [microsoft/markitdown](https://github.com/microsoft/markitdown)
desde `Telegram Desktop/Docs Proyecto` (+ cronograma e instrucciones ya en
`docs/oficiales-vie/`).

| Markdown | Origen |
|---|---|
| `00-INSTRUCCIONES-PROYECTO.md` | PDF “Basado en los documentos…” (enunciado curso) |
| `1-Disposiciones…` | PDF convocatoria (base de negocio) |
| `2-Rubricas…` | XLSX rúbricas investigación 2027 |
| `03-Cronograma-Convocatoria-2027.md` | PDF cronograma (no venía como “3-” en Telegram) |
| `4- Formulario…` | DOCX formulario proyecto |
| `5- Plan…` | XLSX plan de acción / riesgo |
| `6- Plantilla Presupuesto…` | XLSX presupuesto |
| `7- Formato acuerdo coordinadora…` | DOCX |
| `8- Formato acuerdo participante…` | DOCX |

**Nota:** en el paquete de Telegram no hay un archivo `3-…`; el cronograma
oficial está aparte y se mapeó a `03-…`.
