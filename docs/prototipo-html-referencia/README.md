# Prototipo HTML de referencia

**No es código de producción.** Es la captura / export del prototipo UI que sirve como fuente de verdad visual mientras se porta a React.

## Archivos

| Archivo | Uso |
|---------|-----|
| `Fondos-VIE-Prototipo.html` | Prototipo monolítico (referencia 1:1) |
| `analisis/` | Extracciones de rutas, roles, acciones |
| `README-legacy.md` | Notas anteriores del export |

## Regla del repo

- Documentación y referencias → **`docs/`**
- Código ejecutable → `frontend/`, `backend/`, `database/`

El frontend React en `frontend/src` clona layouts y flujos de este HTML. No volver a copiar este archivo dentro de `frontend/`.
